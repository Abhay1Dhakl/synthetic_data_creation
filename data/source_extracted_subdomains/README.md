# Source-Extracted Healthcare Subdomains

This folder contains source-based healthcare text collected from official online sources in the same overall purpose as the root `readme` brachytherapy example.

Rules for files in this folder:

- only source-extracted or tightly source-cleaned text
- no generated sentence expansion
- one subdomain per file
- every block must include the source title and source URL
- only light cleanup is allowed
- do not add new medical claims
